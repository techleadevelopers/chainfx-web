Build automated payment and agent flows

Developers can request quotes, create buy and sell orders, create agent-funded PIX/card payment intents, listen for webhooks, and expose ChainFX MCP tools to agents. The API is designed for server-to-server usage with Bearer secret keys.

GET/rates POST/quote POST/buy POST/sell GET/order/{id} GET/marketplace/capabilities POST/agent/v1/pay POST/mcp/tools/call POST/webhooks/test

PIX to USDT wallet

To generate a real PIX QR Code, create a buy order with BRL amount, USDT asset, destination BSC wallet and optional customer audit fields. Each request creates a unique buy order and returns the PIX payload, QR Code, status URL and access token.

Consolidated with the backend path: /buy accepts customer name, email, CPF, phone, birth date and address, forwards those fields to the PIX provider when creating the PagBank charge, stores audit hashes locally, and returns the PIX QR payload. Current settlement supports USDT delivery on BSC; BTC and EURUSDT remain roadmap assets.

Agent Pay: USDT-funded PIX and card

Agents can create a payment intent for a PIX payout or credit-card bill, deposit the quoted USDT to a unique BSC payment address, and let ChainFX settle the fiat recipient after confirmation.

POST/agent/v1/pay GET/agent/v1/pay/{id} POST/mcp/tools/call createPaymentIntent POST/mcp/tools/call getPaymentIntent
POST /agent/v1/pay 
POST /agent/v1/pay
Authorization: Bearer sk_live_xxx
Content-Type: application/json

{
  "type": "pix",
  "amount_brl": "250.00",
  "pix_key": "financeiro@example.com",
  "idempotency_key": "agent-pay-2026-07-13-001",
  "agent_wallet": "0x174208255ECc40481f7fD7c34EE6a9A5B66B4339"
}

MCP createPaymentIntent 
POST /mcp/tools/call
Authorization: Bearer sk_live_xxx
Content-Type: application/json

{
  "name": "createPaymentIntent",
  "arguments": {
    "type": "credit_card",
    "amount_brl": "420.00",

Agent Pay never settles before the USDT deposit is confirmed. Each intent receives a unique payment address for address-based matching. Overpayment is recorded for operations review and is not auto-refunded.
